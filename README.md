# React + Vite

A beautiful, responsive blog website dedicated to celebrating mothers, featuring stories, health tips, inspiration, and cultural content about motherhood.

## Project Overview

This project is a React.js implementation of a Mother's Day Tribute Blog. It features a modern, responsive design with multiple pages and components to showcase articles and content related to motherhood and Mother's Day celebrations.

The blog is built with a focus on user experience, providing intuitive navigation, clean design, and engaging content presentation. It uses React Router for navigation, CSS for styling, and a local JSON file for data storage.

## How to Run Locally

Follow these steps to run the project on your local machine:

1. **Clone the repository**
   ```bash
      git clone https://github.com/deepak00944/Mother-s-Day-Tribute-Blog-Challenge.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Mother-s-Day-Tribute-Blog-Challenge
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   The application will be running at [http://localhost:3000](http://localhost:3000)

## Features Implemented

### Home Page
- **Hero Carousel**: Dynamic carousel showcasing featured articles with automatic and manual navigation
- **Category Section**: Interactive category cards for filtering articles by topic
- **Article Pagination**: Display of 6 articles per page with pagination controls
- **Search Functionality**: Real-time article filtering based on search terms
- **Responsive Sidebar**: Author profile, highlights, and newsletter subscription

### Navigation
- **Modern Navbar**: Hamburger menu, logo, and search button
- **Overlay Menu**: Full screeen overlay with navigation links
- **Search Overlay**: Full-screen search interface for finding articles

### Article Pages
- **Detailed Article View**: Full article content with author information and metadata(Date and all)
- **Related Articles**: Suggestions for similar articles in the same category
- **Social Sharing**: Buttons to share articles on social media (dummy)
- **Responsive Design**: Optimal reading experience on all devicess

### Categories Page
- **Category Sections**: All categories displayed with their respective articles

### About Me Page
- **Author Information**: Personal details about the blog author
- **Social Media Links**: Connections to author's social media profiles
- **Responsive Layout**: Clean, centered design that adapts to all screen sizes

### Contact Page
- **Contact Form**: User-friendly form for sending messages
- **Contact Information**: Email, phone, and address details
- **Form Validation**: Input validation for required fields

### Additional Features
- **Fully Responsive Design**: Optimized for mobile, tablet, and desktop
- **Smooth Transitions**: Page transitions and hover effects for better user experience

## Technologies Used

- **React.js**: Frontend library for building the user interface
- **React Router**: For handling navigation and routing
- **CSS**: Custom styling with responsive design
- **Lucide React**: For icons throughout the application
- **Local JSON**: For storing and managing article data
